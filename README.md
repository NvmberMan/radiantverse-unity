## 1. Software Requirements (Prerequisites)

Before opening the project, make sure the following software is installed on your computer:

| Software | Purpose | Download Link |
| :--- | :--- | :--- |
| **Unity Hub** | Unity version & project management | https://unity.com/download |
| **Git** | Repository cloning & version control | https://git-scm.com/ |
| **Visual Studio 2022** | C# code editor (IDE) | https://visualstudio.microsoft.com/ |

---

## 2. Installing the Unity Engine (Via Unity Archive)

This project uses a specific Unity version, so it must be installed through the official archive:

1. Open your browser and go to:
   https://unity.com/releases/editor/archive
2. Select the **Unity 6** tab.
3. Locate **Unity 6000.0.21f1** (or the required Unity 6 version).
4. Click **Unity Hub** to start the installation.
5. In the **Install Modules** window, make sure the following modules are enabled:
   - Android Build Support (SDK & NDK Tools)
   - Microsoft Visual Studio Community 2022

---

## 3. Downloading the Project (Cloning the Repository)

Open **Terminal** or **Git Bash**, then run the following commands:

git clone https://github.com/NvmberMan/radiantverse-unity.git
cd radiantverse-unity

---

## 4. Opening the Project & Initialization

1. Open **Unity Hub**.
2. Click **Add → Add project from disk**.
3. Select the **radiantverse-unity** folder.
4. Open the project.
5. If prompted, select Unity version **6000.0.21f1**.

### Import Process

Unity 6 will automatically download and import required packages:
- Spine
- ML-Agents
- Firebase

This process may take **5–15 minutes**, depending on your PC specifications and internet connection.

---

## 5. Running the Game

1. In the **Project** window, open the folder:
   Assets/Scenes/
2. Double-click the **MainMenu** scene.
3. Press the **Play (▶)** button at the top center of the Unity Editor.

---

## Notes

- Make sure your internet connection is stable during the first launch.
- If package import errors occur, restart Unity and let it reimport automatically.
- Android Build Support is required only if you plan to build for mobile devices.
